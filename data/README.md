# Dataset

The raw dataset is intentionally not committed to this repository.

Download `UCI_Credit_Card.csv` from the
[Kaggle dataset page](https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset)
and place it in this folder.

The notebook expects this exact relative path:

`data/UCI_Credit_Card.csv`

The dataset is attributed to the UCI Machine Learning Repository:
https://doi.org/10.24432/C55S3H
